# 蓝图落地进展与简化缺陷清单

本文件用于记录当前代码库相对“最终优化方案蓝图”的落地进展与仍存简化点，便于后续迭代与评审。

## 一、已落地的关键改动（阶段性成果）

### 1. 数据—模型契约（部分落实）
- **NB-VAE** 保留作为 counts 输入的主线。
- **Gaussian VAE** 作为 log-normalized 输入兜底。
- 训练脚本强制检查 `data.input_representation` 与 `model.likelihood` 一致性，避免统计假设混用。

### 2. 扰动算子结构升级
- **Residual + Gated** 结构：`z_out = z + g(θ) ⊙ (A_θ z + b_θ)`。
- **系数 softmax** 约束，确保基矩阵的凸组合，提升稳定性与可解释性。

### 3. 训练目标与稳定性
- 分布级损失：**E-distance** 支持自动 exact/batched 切换。
- 新增 **Δ-loss** 与 **组内一致性正则**（condition-wise variance）。
- 新增 **样本级谱范数约束**（batch-wise power iteration）。
- 控制条件加入 **gate 正则**，鼓励对照条件接近恒等映射。

### 4. 训练策略
- 已具备 **冻结/部分解冻/全解冻** 能力（`finetune_scope`）。
- 支持设定 `finetune_start_epoch` 进行阶段式解冻。

### 5. 评测与对标
- 引入 **PCA E-distance**。
- 引入 **perturbation-specific shift 指标**：Pearson(Δ) 与 Pearson(Δ20)。
- 增加 **简单基线对照**：no-change / mean / matching-mean。

---

## 二、已消除的简化缺陷（落地完成）

### A. 数据切分与评测闭环（P0）
- **Systema 的 unseen split / 组合扰动分层**已在预处理脚本中实现。
  - 新增 `split_data_systema` 并支持 `--split_strategy systema`。

### B. Δ20 的严格防泄漏（P0）
- **Δ20 仅基于训练集 top genes**，评估脚本缺少训练集时默认跳过 Δ20。

### C. 评测基线扩展（P1）
- 新增 **加性扰动基线** 与 **线性回归基线**（依赖训练集配对样本）。

### D. VAE Denoising（P1）
- 训练配置新增 **gene masking** 参数，支持去噪训练。

### E. scPerturb 评测流程细节（P1/P2）
- 评估脚本支持 **HVG筛选 / 条件下采样 / Combat批次校正**。
- 新增 **Systema协议模式** 与 **Δ20分层统计**。

### F. 对照条件门控（P1）
- 增加 **control标签标准化**，避免别名导致的门控正则失效。

## 三、仍存在的简化点（待完善）

### A. 评测基线仍不充分（P2）
- 目前已覆盖线性/加性/条件均值等基线，但仍缺少**更强的统计/因果基线**（如岭回归/弹性网之外的显式因果或更复杂的对照）。
- 建议进一步对齐 Systema 或同类基准的完整基线集合。

### B. Systema官方基准全流程对齐（P2）
- 已实现 split、HVG、下采样、Combat 与 Δ20 分层，但仍未完成**与官方评测协议的完全对齐**（例如固定子集、官方报告字段/格式、特定DE流程）。
